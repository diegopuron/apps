# ScratchLab - Misiones robot

Carpeta modularizada lista para GitHub/Netlify.

## Estructura

- `index.html`: interfaz del juego.
- `css/styles.css`: estilos.
- `js/data.js`: misiones, checkpoints y configuración.
- `js/app.js`: lógica del juego.

Para añadir niveles, edita el array `missions` en `js/data.js`.
